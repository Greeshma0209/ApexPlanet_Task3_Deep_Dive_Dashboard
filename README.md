# ApexPlanet Task 3 – Deep-Dive Analysis & Interactive Dashboarding

## Project Overview
This project is part of the ApexPlanet Data Analytics Internship. It focuses on exploring e-commerce sales data, understanding customer purchasing behaviour, and presenting insights through an interactive Power BI dashboard.

## Objectives
- Analyze e-commerce sales and customer purchasing patterns.
- Track key business performance indicators (KPIs).
- Segment customers based on purchase recency.
- Explore sales performance by category, gender, and city.
- Build an interactive dashboard with category and date filters.

## Tools Used
- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Microsoft Excel / CSV
- GitHub

## Dashboard Features
- Total Sales
- Total Orders
- Average Sales
- Total Unique Customers
- Total Quantity Sold
- Sales by Product Category
- Sales by Gender
- Sales by City
- Customer Segmentation by Purchase Recency
- Top 10 Customers by Spending
- Interactive category and date slicers

## Customer Segmentation
Customers are grouped using purchase recency:
- **Recent Customer:** Last purchase within 30 days
- **Regular Customer:** Last purchase 31–90 days ago
- **At Risk:** Last purchase 91–180 days ago
- **Inactive Customer:** Last purchase more than 180 days ago

These are project-defined business rules and can be adjusted based on business requirements.

## Key Business Questions
- Which product categories generate the highest sales?
- How does sales performance vary by gender and city?
- Which customers have the highest total spending?
- How recently have customers purchased?
- How can interactive filters help explore sales performance?
